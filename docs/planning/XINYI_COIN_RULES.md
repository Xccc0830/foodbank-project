# 心意幣使用規範與獲取方式

心意幣是 GO Rider（志工騎手）完成配送後獲得的點數，可在「心意幣兌換」頁面兌換獎勵。
（原名「興毅幣」，2026-11 起全系統改稱心意幣。）

## 一、獲取方式

食物銀行評估物資後，志工配送單一律發放心意幣（已取消無償、物資、服務時數選項）。
食物銀行自行派車（忠信派車）的單不發幣。

### 配送單基本幣（發布時計算）

| 項目 | 規則 |
| --- | --- |
| 基本幣 | 機車 3 枚、汽車 5 枚 |
| 重量加給 | 每 5 公斤一級，每級 +3，最多 +15（≤5kg +3、≤10kg +6、≤15kg +9、≤20kg +12、20kg 以上 +15） |
| 距離加給 | ≤2 公里 +0、≤5 公里 +2、≤10 公里 +4、10 公里以上 +6 |
| 緊急運送 | +4（商家勾選「緊急運送」，食物銀行審核時同意才給） |
| 冷藏／冷凍 | +2（物資含冷藏或冷凍品項） |

### 完成配送時加給（食物銀行確認收貨時計算）

| 項目 | 規則 |
| --- | --- |
| 準時送達 | 在預估送達時間內完成 +1 |
| 順路配送 | 接單時手上已有進行中的單，每多一站 +1（最多 +3） |
| 首次配送 | 第一次完成配送 +3（一次性） |

範例：機車、8kg、3km、緊急、冷藏 → 3 + 6 + 2 + 4 + 2 = 17 枚（完成時另計加給）。

## 二、防濫用

- 商家每月最多申請 5 單緊急運送。
- 緊急加成需食物銀行審核同意（審核畫面預設勾選，可取消）。
- 加給只發給 GO Rider；取貨需拍照、送達需食物銀行確認收貨，才會入帳。

## 三、使用方式

- GO Rider 於「心意幣兌換」頁以心意幣兌換食物銀行或愛心商家提供的獎勵。
- 兌換後由食物銀行／商家核銷，並發送通知。

## 四、營運模式（定案）：以「折扣」方式使用，不開放捐款換幣

**決議：心意幣只能靠「完成志工配送」賺取，並由愛心商家以「折扣／優惠」的方式提供兌換獎勵。不開放大眾用捐款或購買換取心意幣。**

### 為什麼選折扣、不選捐贈換取

| 比較 | 折扣（採用） | 大眾捐贈換取（不採用） |
| --- | --- | --- |
| 金流 | 不碰金錢，系統只記錄點數 | 需要收款、對帳、開收據，須符合募款與支付相關規定 |
| 公平性 | 幣只能靠實際出力賺取，代表真實貢獻 | 有錢就能換幣，會稀釋志工貢獻的意義 |
| 商家意願 | 商家出優惠、換取曝光與好感，成本自己控制 | 需另外設計資金分配與退款機制 |
| 系統成本 | 現有兌換頁與商家獎勵方案即可運作 | 需新增付款、帳務、稽核功能 |
| 防濫用 | 賺幣需拍照與確認收貨，難以灌水 | 洗錢、刷幣風險 |

### 運作方式

1. **賺幣**：GO Rider 完成配送，依第一節規則入帳。
2. **兌換**：GO Rider 在「心意幣兌換」頁，用心意幣兌換愛心商家提供的折扣券或優惠品項，以及食物銀行提供的獎勵。
3. **商家**：愛心商家在「心意幣兌換」頁自行建立獎勵方案（名稱、分類、所需心意幣、庫存）。食物銀行可審核與管理。
4. **核銷**：兌換後產生優惠券，由商家或食物銀行核銷並發送通知。
5. **大眾的參與方式**：一般大眾可透過「公益活動」報名、捐贈物資、成為 GO Rider 賺取心意幣，而非直接購買。

### 營運注意事項

- 心意幣不可轉讓、不可換成現金。
- 獎勵的折扣內容與使用期限由提供者決定，須在方案中寫清楚。
- 商家的獎勵方案需符合廣告與內容審核規範（見廣告機制）。

## 五、調整數字

各項數字日後如需調整，只需修改 `DeliveryModel::calculatePoints()`、`finalizeDeliveryCompletion()` 的加給，以及審核畫面的預覽公式。
