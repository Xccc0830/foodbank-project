# 心意幣使用規範與獲取方式

心意幣是 GO Rider（志工騎手）完成配送後獲得的點數，可在「心意幣兌換」頁面兌換獎勵。
（原名「興毅幣」，2026-11 起全系統改稱心意幣。）

## 一、獲取方式

食物銀行評估物資後，志工配送單一律發放心意幣（已取消無償、物資、服務時數選項）。
食物銀行自行派車（忠信派車）的單不發幣。

### 配送單基本幣（發布時計算）

| 項目 | 規則 |
| --- | --- |
| 基本幣 | 機車 3 枚、汽車 5 枚 |
| 重量加給 | 每 5 公斤一級，每級 +3，最多 +15（≤5kg +3、≤10kg +6、≤15kg +9、≤20kg +12、20kg 以上 +15） |
| 距離加給 | ≤2 公里 +0、≤5 公里 +2、≤10 公里 +4、10 公里以上 +6 |
| 緊急運送 | +4（商家勾選「緊急運送」，食物銀行審核時同意才給） |
| 優先配送 | +2（食物銀行建立或編輯配送任務時選「優先配送」；與緊急運送擇一） |
| 冷藏／冷凍 | +2（物資含冷藏或冷凍品項） |

### 完成配送時加給（食物銀行確認收貨時計算）

| 項目 | 規則 |
| --- | --- |
| 準時送達 | GO Rider 按「我已送達食物銀行」的時間在預估送達時間內 +1（沒按時以食物銀行確認收貨的時間判斷） |
| 順路配送 | 接單時手上已有進行中的單，每多一站 +1（最多 +3） |
| 首次配送 | 第一次完成配送 +3（一次性） |

範例：機車、8kg、3km、緊急、冷藏 → 3 + 6 + 2 + 4 + 2 = 17 枚（完成時另計加給）。

## 二、防濫用

- 商家每月最多申請 5 單緊急運送。
- 緊急加成需食物銀行審核同意（審核畫面預設勾選，可取消）。
- 加給只發給 GO Rider；取貨需拍照、送達需食物銀行確認收貨，才會入帳。

## 三、使用方式

- GO Rider 於「心意幣兌換」頁以心意幣兌換食物銀行或愛心商家提供的獎勵。
- 兌換後由食物銀行／商家核銷，並發送通知。

## 四、營運模式（定案）：以「折扣」方式使用，不開放捐款換幣

**決議：心意幣只能靠「完成志工配送」賺取，並由愛心商家以「折扣／優惠」的方式提供兌換獎勵。不開放大眾用捐款或購買換取心意幣。**

### 為什麼選折扣、不選捐贈換取

| 比較 | 折扣（採用） | 大眾捐贈換取（不採用） |
| --- | --- | --- |
| 金流 | 不碰金錢，系統只記錄點數 | 需要收款、對帳、開收據，須符合募款與支付相關規定 |
| 公平性 | 幣只能靠實際出力賺取，代表真實貢獻 | 有錢就能換幣，會稀釋志工貢獻的意義 |
| 商家意願 | 商家出優惠、換取曝光與好感，成本自己控制 | 需另外設計資金分配與退款機制 |
| 系統成本 | 現有兌換頁與商家獎勵方案即可運作 | 需新增付款、帳務、稽核功能 |
| 防濫用 | 賺幣需拍照與確認收貨，難以灌水 | 洗錢、刷幣風險 |

### 運作方式

1. **賺幣**：GO Rider 完成配送，依第一節規則入帳。
2. **兌換**：商家在「心意幣兌換」頁顯示並列印本店固定 QR Code；GO Rider 用手機相機或頁面的掃碼功能掃描，登入後選擇本店優惠並確認扣點。也可由「查看合作商家」搜尋店名、地址、優惠或篩選優惠方式。頁面列出店家登記的取貨地址與營業資訊；已兌完或已停用商家的優惠不能再領取。食物銀行獎勵仍可由兌換目錄領取。
3. **商家**：愛心商家在「心意幣兌換」頁的「我的獎勵方案」選擇新增或編輯，進入獨立的優惠模板頁。選定下列方式後填入本店的名稱、分類、庫存及優惠條件；每個商家的每個方案各自設定，食物銀行可管理方案。
   - 商品直換：以固定點數兌換商品，不需現金。
   - 滿額現金折抵：消費達門檻後，每點折抵 1 元；所需點數等於折抵金額，門檻不得低於折抵金額。
   - 滿額點數打折：消費達門檻後，支付設定的點數取得整單折扣；實收金額四捨五入至整元。
4. **核銷**：會員自行扣點後，向商家出示兌換編號，商家在兌換紀錄核實；滿額優惠由商家輸入實際帳單，達門檻才能核銷。系統保留領券當時的規則並記錄原金額與實收現金；打折後金額四捨五入至整元，且不超過原帳單。食物銀行禮品仍由食物銀行核銷，舊的會員 QR Code 核銷方式亦可使用。
5. **大眾的參與方式**：一般大眾可透過「公益活動」報名、捐贈物資、成為 GO Rider 賺取心意幣，而非直接購買。

### 營運注意事項

- 心意幣不可轉讓、不可換成現金。
- 會員可自行取消尚未核銷的券，系統會退回原扣點數；已核銷或已取消的券不能再退點。新券若領取時扣過有限庫存，取消時會恢復庫存（目前為不限量時不變）；舊券沒有庫存快照，若目前有限量，需由提供者人工確認庫存。商家停業或爭議可先由會員取消待核銷券；已核銷的爭議仍需人工處理。
- 店家固定碼不含登入憑證。手機須能連上店家列印時所用的網址；`localhost` 只適合本機測試，跨裝置及手機瀏覽器相機需使用可連線的 HTTPS 網址。
- 舊版商家方案及已領取的舊券預設視為商品直換；舊資料沒有低消或折扣比例，店家應檢查並重新設定方案，已發出的舊券不會因修改方案而改變。
- 獎勵的折扣內容與使用期限由提供者決定，須在方案中寫清楚。
- 商家的獎勵方案需符合廣告與內容審核規範（見廣告機制）。

## 五、調整數字

各項數字日後如需調整，只需修改 `DeliveryModel::calculatePoints()`、`finalizeDeliveryCompletion()` 的加給，以及審核畫面的預覽公式。
