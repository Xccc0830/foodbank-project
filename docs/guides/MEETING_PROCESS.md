# 專案會議標準流程與紀錄模板

> 目的：統一每次會議流程，降低重複溝通成本，節省團隊時間。

## 一、固定會議流程（每次皆適用）

1. 上次會議待議/待完成事項（若有）
2. 專案進度報告/討論
   - 對應專案驗收（proposal、predemo、final）時程完成百分比
   - 各工作項目註明：負責人、預期完成日、進度狀態（進行中、待處理、已處理、需協助、待確認）
   - 需提請團隊討論之進度議題
3. 專案文件報告/討論
   - 本次增修刪內容
   - 需提請團隊討論之文件議題
4. 下次會議規劃（預計進度/預計完成事項/待確認事項）
5. 臨時動議

## 四、執行規範

- 由小組長或指定記錄者於會前複製模板。
- 每個工作項目必填：負責人、預期完成日、進度狀態。
- 會後 24 小時內完成紀錄並同步給全體成員。
- 下次會議第 1 項必須回顧上次未結事項。
