**角色**: 數據庫與後端邏輯  
**優先級**: 🔴 高 → 🟡 中  
**預計工期**: 2-3 天

### 主要任務

**1. 執行數據庫遷移** ⭐ 關鍵
- [ ] 執行 4 個 SQL 遷移文件
  ```bash

  001_add_item_categories.sql
  002_donations_evaluation_system.sql
  003_add_enterprise_verification.sql
  004_add_donor_rewards.sql
  ```
- [ ] 驗證表結構是否正確
- [ ] 檢查外鍵關係
- 📍 影響度：🔴 阻止所有相關功能

**2. 商家獎勵方案功能調試** ⭐ 關鍵
- [ ] 測試新增獎勵方案是否能保存到數據庫
- [ ] 調試 `src/views/rewards.php` 的 POST 處理邏輯
- [ ] 驗證獎勵兌換流程
- [ ] 確保庫存管理正常
- 📍 相關文件: `src/models/RewardModel.php`, `src/views/rewards.php`

#### 🟡 中優先級

**3. 商家兌換紀錄後端支持**
- [ ] 在 `RewardModel.php` 添加方法獲取商家的兌換紀錄
- [ ] 實作狀態更新方法（標記已完成/已取消）
- [ ] 添加數據導出功能

### 檢查清單
- [ ] 所有遷移執行成功，表結構完整
- [ ] 商家能成功新增獎勵方案
- [ ] 兌換數據正確保存到 `donor_reward_redemptions` 表
- [ ] 沒有 SQL 注入或數據完整性問題

### 交付物
- ✅ 數據庫遷移完成報告
- ✅ 功能測試結果
- ✅ 後端邏輯確認文檔
