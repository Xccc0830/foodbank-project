# 2026-09-30 系統變更紀錄

## 角色與權限

- 將 `admin` 角色併入 `foodbank_staff`。
- 會員角色統一使用 `member`，並以 `member_type` 區分一般會員與企業會員。
- 移除舊有 `volunteer`、`donor` 角色相容判斷。
- 管理介面權限整合至食物銀行職員。

## 功能移除

- 移除舊版捐贈管理頁面。
- 移除舊版評估派車頁面。
- 移除受益者管理功能及相關 Model。
- 移除庫存管理相關 Model 與報表查詢。
- 移除舊版 `DonorModel`。

## 名稱調整

- 使用者介面中的「志工」統一更名為「忠信GO RIDER」。
- 管理員工作台改為「管理介面」。
- 更新配送、排行榜、兌換、通知及同意頁面的相關文案。

## 配送與物資流程

- 接受物資時，配送方式改為必填。
- 配送方式表單改用必選單選按鈕。
- Model 層同步驗證配送方式，避免直接繞過表單提交空值。
- 修正訂單追蹤頁連結，改連至新版物資頁面。
- 配送方式正式收斂為「忠信派車」與「忠信GO RIDER派車」。
- 舊有捐贈方自送資料會遷移為忠信派車。

## 興毅幣

- 使用者可見的「公益點數」文案改為「興毅幣」。
- 保留 `points`、`cost_points`、`points_spent` 等資料欄位，避免破壞既有兌換資料與計算流程。

## 愛心商家

- 企業會員儀表板新增「我的永續報告」區塊。
- 顯示該企業完成配送趟次、捐贈重量、配送里程與避免浪費估算。
- 報表僅依目前企業會員的 `donor_id` 顯示資料。
- 新增 `donation_items` 物資明細表。
- 物資捐贈表單區分「物流主表」與「物資明細」。
- 新捐贈會同步建立一筆明細，既有捐贈資料可由遷移腳本回填。

## 資料庫

- 整合 `database/shinigyi_foodbank (4).sql`，新安裝不再需要額外執行 migration。
- 角色遷移為 `foodbank_staff` 與 `member`。
- 移除受益者、庫存及舊捐贈者相關資料表。
- 更新 SQL 快照中的角色、示範帳號、活動與通知資料。
- 更新安裝指南，說明整合 SQL 的匯入與備份注意事項。

## 驗證結果

- 全專案 PHP 語法檢查通過。
- JavaScript 語法檢查通過。
- 既有點數測試通過，輸出 `24`。
- 已確認程式碼不再查詢受移除的庫存與受益者資料表。
